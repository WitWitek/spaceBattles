# spaceBattles
space shooter game in java



SpaceBattles

Prosty kosmiczny shooter stworzony w Javie (Swing).
Gra dostępna jest w formie EXE spakowanego w ZIP, więc nie trzeba instalować Javy ani uruchamiać JAR — wystarczy pobrać i uruchomić plik wykonywalny.

Simple space shooter written in Java (Swing).
The game is provided as a ZIP containing a ready-to-run EXE, so you don’t need Java installed and you don’t run any JAR — just download, extract, and run the executable.

🇬🇧 Game Description (EN)

SpaceBattles is a fast-paced top-down arcade shooter.
You control a spaceship, dodge incoming enemies, destroy targets, and try to survive as long as possible while scoring points.

Features:

dynamic arcade gameplay,

enemies approaching from multiple directions,

lightweight 2D visuals,

score system,

keyboard controls.

How to run:

Download the ZIP from: https://virtualgrindsoftwarehouse.com/SpaceBattles.php

Extract the ZIP archive.

Run SpaceBattles.exe.
(No Java installation required)
